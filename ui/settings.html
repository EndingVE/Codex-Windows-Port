Menu bar

Draw the used percentage into the icon
Shows the rounded percent next to the donut gauge in the notification area (showPercentInIcon).
Show the colour legend
A one-line key above the command list explaining the green / amber / red severity thresholds. Stored with the UI, not the provider config.

Advanced

Credential handling and stored settings.

Credentials

Refresh credentials on every fetch
Re-read provider credential stores each refresh cycle instead of reusing the cached copy. Slower, but picks up externally rotated tokens immediately.
